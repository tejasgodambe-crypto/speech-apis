Reading guide and evidence rules

Coverage means documented support, not independently tested recognition quality. Generic English is not automatically Indian English. A language list for a vendor, open model, default model or cloud edition is not transferred to a different domain model, API mode or deployment. A row may group versions of the same general API when their differences are stated; specialized domains are separated when qualification is established.

Access categories: HTTP synchronous; HTTP asynchronous/batch; HTTP API with response mode unverified; WebSocket streaming; gRPC streaming; HTTP/2 streaming; SDK streaming/events; local SDK. An API using HTTP/gRPC for recorded audio is not necessarily a live streaming API. Callbacks and polling are result-delivery mechanisms.

Deployment/distribution categories: managed cloud; private/self-hosted (private cloud or on-premises); edge/local; marketplace distribution; government platform distribution. Conditional category labels must be read with the model-specific entitlement caveat in the same cell. Direct vendor API distribution is stated where established.

Prices: USD unless ₹ is shown. Preserve original units; an “audio hour,” attendee-minute, credit, token, connector-day and bundled contact-center minute are not interchangeable. Published rates are reference rates with the stated region, model and tier, not quotes. Infrastructure, tax, storage, add-ons and commitments are included only when documented. Quote-only is not a numeric rate. A listed rate does not establish all deployment combinations.

Sources: Each extracted-data cell contains its relevant HTTP links. Links in an unverified field identify material reviewed; they do not prove absence. First-party product, pricing, repository and case-study pages supplement formal docs. This broader source set is disclosed in the audit because your literal rule names official API docs or AWS/Azure Marketplace. The review covers sources checked on 21–22 September 2026; older official changelogs are dated in the row where used.

Customers: Named examples require a documented connection between the API and Indian-language or Indian-English use. Supernova establishes Sarvam API-level use, not a Saaras version. Creditas establishes the described custom Nova deployment, not Nova-3 generally. Logos and vendor-wide partnerships are excluded.
